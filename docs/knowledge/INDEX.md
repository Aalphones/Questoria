# Knowledge Index — Questoria

Projekt-eigener Wissenskatalog: Domänen-Fakten und Referenzen, die das Modell
nicht ohnehin weiß (Fandom-Lore-Details, Hosting-Spezifika, o.ä.). Bei Bedarf
pro Eintrag eine Zeile ergänzen.

- [Ersten Account anlegen](erster-account.md) — einziger Weg, einen Account auf
  dem Server anzulegen (kein Registrierungs-UI, keine Kommandozeile dort).
- [Druckbogen-Geometrie](druckbogen-geometrie.md) — Maße, Rechnung,
  Schnittlinien und der PDF-Ausgabeweg für den A4-Kartenbogen. Erprobte
  Vorlage, vollständig hier abgelegt.
- [Spielmechaniken-Katalog](spielmechaniken-katalog.md) — alle gesammelten
  Spielideen: Kernspiele, Auflockerungsspiele und Franchise-Mechaniken je Welt,
  mit Stand und Bewertung. Ideenspeicher, aus dem geplant wird — kein Fahrplan.
- [Lerninhalte Hessen, Klasse 1](lerninhalte-hessen-klasse-1.md) — Katalog
  stabiler Lernziel-IDs für Deutsch, Mathematik und Sachunterricht, auf die
  Aufgaben über `learning_objectives` zeigen. Fachliches Content-Backlog für
  neue Welten; Abschnitt 14 enthält die Questoria-Ergänzungen.
